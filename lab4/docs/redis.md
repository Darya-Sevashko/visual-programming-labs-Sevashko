\# Работа с Redis в n8n



В ходе выполнения лабораторной работы №4 я настроила интеграцию n8n с базой данных Redis.



\## Подключение (Credentials)



В n8n я создала новые Credentials для Redis:



\* \*\*Host\*\*: `host.docker.internal` (обеспечивает связь контейнера n8n с Redis, запущенным на хост-машине).

\* \*\*Port\*\*: `6379`.

\* \*\*Password\*\*: оставлено пустым, так как локальный Redis запущен без пароля.



\## Поток 1. Создание и чтение ключа (flow-09-redis.json)



Этот поток состоит из трех нод:



1\. \*\*Manual Trigger\*\* — запуск вручную.

2\. \*\*Redis (Set)\*\* — записывает ключ `Sevashko` со значением `"Hello from Redis!"`.

3\. \*\*Redis (Get)\*\* — читает значение по ключу `Sevashko`.



В Output ноды Get выводится строка `"Hello from Redis!"`. Это подтверждает, что ключ был успешно создан и прочитан.

\## Поток 2. Удаление и проверка (flow-10-redis.json)



Этот поток состоит из трех нод:



1\. \*\*Manual Trigger\*\* — запуск вручную.

2\. \*\*Redis (Delete)\*\* — удаляет ключ `Sevashko`.

3\. \*\*Redis (Get)\*\* — снова пытается прочитать удаленный ключ.



В Output ноды Get выводится значение `null`. В n8n и Redis `null` означает, что такого ключа не существует. Это доказывает, что операция удаления прошла успешно.
